Why measurement comes first

Most AI writing reports the systems that work. In legal practice the work that matters is the distance between a model that sounds authoritative and a model that is correct. That gap is where the risk sits, and it has to be measured rather than assumed.

Three questions a firm has to answer

Is it accurate enough?

Measured on the firm's own kind of work, not on a vendor's leaderboard. A model that invents a case is worse than one that admits a gap.

See auslawexam-bench and contract-clause-classifier

Where does client material go?

Confidential and privileged material either leaves for a provider's servers or stays on hardware the firm controls. Both are defensible, and the choice should be deliberate.

See local-llm-inference-notes and intake-agent

What does each answer cost?

Cost per task, read from every response, decides whether a tool scales from a pilot to a practice group. Restructuring one prompt cut a full run from 1,560 calls to 130.

See contract-clause-classifier and intake-agent

Selected work

intake-agent Working prototype

A Claude agent that triages a new client enquiry. It checks conflicts through a tool, applies the firm's intake policy, and drafts a practitioner summary and a holding reply that gives no advice. The conflict check, the routing rules, and an advice check on the reply run in code, so every doubtful case goes to a person.

Tested against a mocked API, with a deterministic evaluation of 30 synthetic enquiries and an offline rules baseline. The Claude arm has not yet been run against the live API.

auslawexam-bench Working prototype

A reproducible benchmark of Australian legal reasoning for language models. Its headline metric is how often a model invents a citation, which is the exposure a law firm actually carries.

16 provisional questions, with every authority in the answer key checked against public sources. The Claude, GPT, and Gemini slots are wired and tested against mocked APIs, and one real run of a local open-weight model is committed with its raw outputs. View the leaderboard.

contract-clause-classifier Built, not yet measured

A zero-shot language model against a fine-tuned transformer on CUAD contract clauses, compared on precision, recall, F1, cost, and latency, and framed as a build-or-buy decision.

The Claude arm asks about every clause type in one call per chunk, which cuts a full test run from 1,560 calls to 130. No comparison run has been published yet.

legislation-monitor Working prototype

Change detection over Commonwealth and Victorian legislation. It fetches each Act on request, diffs it against the last version, and has Claude or a local model write a plain-English brief of the amendment, labelled with where the brief came from.

113 tests and CI on every push. It has not yet been checked against the live registers.

legal-rag-evaluation Working prototype

Hybrid retrieval over Australian statute. Claude answers with citations to the exact sections it retrieved, and a checker flags any section reference the retrieved text does not support.

One earlier two-Act run is committed with its provenance. A provisional 36-question Fair Work Act set is ready to run at section level.

How I work

  • Criteria before results.Noise bands and success criteria are declared before a run. A band chosen after seeing the numbers is a rationalisation. The rules are written down in METHOD.md.
  • Negative results get published.Eight of the sixteen inference investigations end in no, and several of them overturned a claim the repository had already made.
  • Every number traces to a commit.Each benchmark, prompt, and published result lives in version control, next to the code and the run that produced it. Linters and tests run in CI on every push.
  • Unmeasured means unclaimed.Where something has not been run, the project says so plainly, and the command to run it sits beside the claim.
  • Fixes go upstream.A crash fix for GGUF tensors was merged into molbal/ComfyUI-GGUF the night it was reported.
Every project on this page is public on GitHub, with its tests, its method, and what it has not yet measured.
