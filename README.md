# danielkgr.github.io

The source of [danielkgr.github.io](https://danielkgr.github.io/), a one-page summary of my work on AI for legal practice.

It is a single `index.html` with inline styles and no build step, so GitHub Pages serves it as it is.  `.nojekyll` turns Jekyll processing off.  The page follows the system's light or dark setting and works down to a 320-pixel phone screen.

Every project it describes links to a public repository with its tests, its method, and what it has not yet measured.  When a project's status changes, update its card here and its row in the [profile README](https://github.com/Danielkgr/Danielkgr) together.
